# 海上丝绸之路大富翁 - 自定义地图 AI 语义指南

## 概述

地图编辑器支持通过 MCP (Model Context Protocol) 集成 AI 助手，帮助创建和优化地图。

## 地图主题元素

### 港口属性
- `name`: 港口名称 (如: 泉州港、广州港、占城港)
- `region`: 所属地区 (如: 中国东南沿海、东南亚、印度洋)
- `basePrice`: 购买价格 (银两)
- `tollFees`: 各等级过路费数组
- `specialty`: 港口特产 (如: 丝绸、瓷器、茶叶)

### 航海事件 (机会卡)
- `typhoon` (台风): 损失银两/损坏船只
- `pirates` (海盗): 被劫掠
- `fair_wind` (顺风): 额外移动
- `trade_boom` (贸易繁荣): 获得银两
- `mirage` (海市蜃楼): 随机传送
- `imperial_reward` (朝廷赏赐): 获得银两
